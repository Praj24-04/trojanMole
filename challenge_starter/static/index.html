Project Description

This platform demonstrates backdoor attacks and robust defenses in Federated Learning (FL) for dermatological diagnostic systems using the HAM10000 dataset. It showcases how malicious clients can inject backdoors using real physical dermoscopic ruler/marker artifacts (forcing malignant melanoma, basal cell carcinoma, and pre-malignant lesions to be misclassified as benign nevi), and evaluates 6 robust aggregation defenses alongside our multi-stage Sybil-Filtered FLAME defense.

Key Insights

FedAvg Vulnerability: Without outlier filtering, standard FedAvg is highly susceptible to targeted backdoor attacks.
Krum Robustness: By selecting a single trusted model, Krum effectively nullifies the backdoor injection.
Trimmed Mean Balance: Offers a strong trade-off by removing outliers across each dimension while preserving benign variance.
Norm Clipping Challenge: Attackers can bypass norm clipping by scaling down malicious updates to match benign bounds.
